The event loop will execute one coroutine at a time. When a coroutine hits await, it yields control and another coroutine runs.

💡 The Key Insight
Only one coroutine runs at a time — there's no parallelism. But while Rollout 1 waits for a network response, the event loop switches to Rollout 2, then 3, etc. This is concurrency without parallelism.
